# CNB2API Android 网关

把 DSH 插件 `dsh-cnb2api` 的能力搬到安卓手机：手机本身跑一个**固定地址**的
OpenAI 兼容网关（`http://<手机IP>:41729/v1`），其它 AI 客户端只需填一次这个地址。
工作区地址漂移、账号切换、额度耗尽换人，全部发生在网关后面。

> 这是独立 Android 工程，不是 DSH 插件；协议与判定口径参照插件 `lib/gateway.mjs`、
> `lib/monitor.mjs`、`lib/quota.mjs`、`lib/models.mjs` 实现。

---

## 1. 与 DSH 插件的能力对照

| 插件实现 | 安卓端 | 说明 |
|---|---|---|
| `lib/gateway.mjs` 固定基址网关 | ✅ | NanoHTTPD 监听 `::`（双栈，兼顾 IPv4/IPv6），可按设置改端口 |
| 访问密钥鉴权 + 局域网保护 | ✅ | `Authorization: Bearer <key>` / `x-api-key`，恒定时间比较 |
| 多账号按可用性择优 | ✅ | 可达优先、余额多者优先；额度未知不拦 |
| 上游 401/402/5xx 同请求内换号 | ✅ | 429/5xx 全部重试，400/422 原样透传 |
| 失败账号冷却 60 秒 | ✅ | 只降权不排除 |
| 保底线硬停 / 警戒线提示 | ✅ | 低于保底线的账号完全不派活，也不自动启动 |
| SSE 流式逐块转发 | ✅ | OkHttp 流 → NanoHTTPD chunked，空闲不切断 |
| 额度响应头 | ✅ | `x-cnb2api-credit-remain/total/low/notice` |
| `lib/quota.mjs` 含冻结的三接口账目 | ✅ | 已用+冻结算消耗，`remain` 为真实可用 |
| `lib/monitor.mjs` 地址跟随与自动启动 | ✅ | 启动日志 `PROXY_URI=` 取地址，`/health` 探活 |
| `cnb2api_status/start/quota` 工具 | ⚠️ | 手机端以 `/status` + 界面按钮替代 |
| 自动写入 DSH「设置 → 模型」 | ❌ | 手机不改 DSH 配置；改为把地址填给别的客户端 |

## 2. 在其它 UI 中接入

在同一 Wi-Fi 下，任意 OpenAI 兼容客户端填：

```
Base URL : http://<手机IP>:41729/v1
API Key  : 设置页显示的访问密钥（默认 sk-cnb2api-android，建议改）
Model    : deepseek-v4.1-flash（或设置页里的模型清单）
```

IP 显示与设置是**单向决定关系**：设置里的监听方式决定网关绑定到哪个地址族，仪表盘只列该方式下真正可达的地址——
- 仅本机（127.0.0.1）：只显示 `http://127.0.0.1:端口/v1`
- 所有地址（双栈 `::`）：默认显示本机 + Wi‑Fi/以太网 IPv4/IPv6（标「主」）；缺少局域网时用移动数据 IPv6 兜底，其余移动数据/副网卡地址归入「查看全部地址」。IPv6 为全局地址，是否可被外部访问取决于运营商、路由器与防火墙，不承诺可反连

不再出现「选了某种协议却显示一个没在监听的地址」这种情况。账号页用于增删账号，日志页看巡检记录。

### 仪表盘

界面采用 **iOS 风格**并做了精致化：更紧凑的字号与行高、分组 inset 列表、系统色
（蓝/绿/橙/红）、圆角卡片、iOS 开关、细线条矢量图标（无 emoji）、自定义自适应启动
图标，底部标签栏使用 **Haze 真毛玻璃**（Android 12+ 走 RenderEffect 实时模糊），
状态栏沉浸式（edge-to-edge）且图标颜色随深浅色自动反转。账号列表折叠后是紧凑单行（状态点 + 名称 + 额度摘要 + 百分比），点开才展开环形图与详情，标题行显示「共 N 个账号」并提供一个「展开全部 / 收起全部」切换；工作区状态卡同样可折叠，折叠时只留一行「网关运行中 · 当前账号」。仪表盘的「访问地址」按当前监听方式列出可用地址（本机 + 局域网 IPv4/IPv6；IPv6 可访问性受网络环境影响），每条都可复制；设置里的监听地址只分两种：仅本机 127.0.0.1 / 所有地址（双栈 ::）；外观（跟随系统/浅色/深色）与主题色（蓝/绿/紫/橙/粉/石墨）选择即预览、保存后持久化；账号折叠与日志筛选状态跨页签保留。首页一屏回答「能不能用、谁在用、还剩多少」：
顶部四个指标，中间网关分组卡，下面每个账号一张卡，用**环形进度**显示 credits 消耗比例，
按状态着色（正常蓝、额度告急/启动/掉线橙、配置异常红、未知灰），同时给出 credits 与核时
已用 / 可用、当前派活标记和启动/刷新/删除按钮。

### 本地端点

| 路径 | 作用 |
|---|---|
| `GET /health` | 本机健康检查，返回 `{"status":"ok"}` |
| `GET /v1/models` | 模型清单（本地生成，无需上游） |
| `POST /v1/chat/completions` | 转发到工作区网关，支持流式 |
| 其它 `/v1/*` | 原样转发到选中的工作区 |
| `GET /status` | 账号状态、额度、网关统计、最近日志（需密钥） |

请求头 `x-cnb2api-account: 组织/仓库` 可指定账号；指定账号不可用时直接拒绝，不会悄悄换号。

## 3. 构建与安装

需要 JDK 17、Android SDK 35（`compileSdk`/`targetSdk` 均为 35）、Gradle 8.7（wrapper 已包含 jar 与脚本）。

```
cd android-app
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

首次启动会申请通知权限并拉起前台服务；锁屏、切后台后网关继续运行。

沙箱环境若不允许写 `~/.gradle` 或 `~/.android`，可重定向：

```
export GRADLE_USER_HOME=/tmp/gradle-home
export ANDROID_USER_HOME=/tmp/android-home
export ANDROID_HOME=$HOME/Android/Sdk
export JAVA_HOME=<JDK17 路径>
```

## 4. 账号配置

三种方式：

1. **引导式添加**：账号页 → 添加账号，按 4 步向导走：① 粘贴令牌并验证 → ② 从真实组织列表选择 → ③ 从仓库列表选择（标出运行中）→ ④ 填 PROXY_KEY 与分支，最后确认保存。
2. **从 DSH 配置迁移**：把账号写成 `accounts.json` 放到
   `/sdcard/Android/data/com.ikoude.cnb2api/files/accounts.json`，首次启动（且无账号）自动导入：

```json
[
  {"token":"CNB 访问令牌","repo":"acme/gateway","proxyKey":"sk-...","branch":"main","port":9001}
]
```

3. 手动在设置里改全局端口、巡检间隔、警戒线/保底线和网关密钥。

令牌 scope：最小 `repo-cnb-trigger:r` + `account-engage:r`；自动启动加
`repo-cnb-trigger:rw`；显示额度加 `group-resource:r`。

## 5. 真机验证记录

在 Xiaomi 23113RKC6C（Android 16）上验证：

- `adb install -r` 成功，前台服务启动，`/health` 返回 200 `{"status":"ok"}`。
- 无密钥访问 `/v1/models` 返回 401；带密钥返回模型清单。
- 导入 4 个账号后，`/status` 显示四个组织的 credits / 核时，数字与 DSH 插件
  `cnb2api_quota` 一致（额度均已用尽，核时分别为 1222.1 / 1442.1 / 1352.2 / 1481.9 h）。
- 默认保底线 1% 时四个账号全部停用，聊天请求返回 503，不会白烧核时。
- 临时把保底线改成 0 后，`qdirs/cnb2api` 变为当前账号；上游返回 402
  `[EXCEEDING_LIMIT]`，网关把中文错误原文透传给客户端。
- 验证后已把保底线恢复为 1%。

## 6. 安全与边界

- 令牌与 PROXY_KEY 用 Android Keystore 加密存储，`allowBackup=false`。
- 监听「所有地址」等于把额度开放给局域网，密钥不要外泄。
- 不提供空闲自动停止；工作区重启需 30–90 秒且地址会变。
- 不合并组织额度；同一组织多仓库共用一份。
- 额度用尽时不会自动启动，额度恢复后巡检会补启动。

## 7. 与 DSH 插件 0.9.11 的对照

已移植的关键行为：

- 账号卡默认收起，新添加的账号默认展开；一个「展开全部 / 收起全部」切换。
- 组织候选带**每个组织的额度**（可用/总额、已用尽、额度未知），个人命名空间
  仅在用户名下确有仓库时列出并标「个人空间」。
- 启动日志地址解析：兼容 ANSI 颜色码、`PROXY_URI:` / `PROXY_URI =`、末尾标点，
  以及日志直接打印网关主机（无 `PROXY_URI=` 前缀）的兜底。
- PROXY_KEY 预校验（`GET /v1/models` 探鉴权），上游错误按 402/408/429/5xx 归类并截断正文。
- 网关：监听非回环地址必须先有访问密钥；上游空闲 120 秒、写 60 秒；支持 `Content-Length` 与 `Transfer-Encoding: chunked` 请求体，兼容 JSON `image_url`（base64/URL）图片消息；请求体 64MiB 上限；
  失败账号冷却 60 秒只降权不排除；响应头已发出后不换号。
- 只改 PROXY_KEY 时网关立即用新密钥（旧监视器同步更新凭据）。
- 额度并发查询等待在途结果，不再返回空账；组织额度查询并行化。

有意保留的差异（不是缺陷）：

- `/v1/models` 在本地生成，工作区停止时其它 UI 仍能发现模型；密钥校验由添加账号向导
  直连上游 `/v1/models` 完成。
- 「所有地址」用双栈 `::` 绑定；优先用系统活动网络判定真实地址并标「主」；默认只展示本机 + 局域网地址，移动数据 IPv6 仅在无局域网时兜底显示。
- DSH 宿主专属的悬浮球、插件详情页/标签页、`autoPublish`、工具注册与 MCP 不适用手机端；
  对应能力由仪表盘、账号/设置页与前台服务承担。

## 8. 界面细项

- 仪表盘「访问地址」按可访问范围展示：本机回环、Wi‑Fi/以太网 IPv4/IPv6；移动数据 IPv4 隐藏，移动数据 IPv6 默认不展示（无局域网时兜底），并标注「移动数据全局 IPv6，运营商常限制入站，不能保证可反连」。
  移动数据 IPv4、VPN 接口与 IPv6 临时/隐私地址不获取、不展示；移动数据 IPv6 仅在无局域网地址时兜底展示。
- 设置页顶部为「外观」（模式与主题色选择即预览），其次是「底部导航栏」：
  箭头调整页签顺序，开关控制显隐。**设置页固定显示**，避免把它藏起来后无法恢复；
  其余页可以全部隐藏，此时只剩设置页，仍可改回来。
- 日志页刷新按钮在标题栏右侧，筛选默认「全部」，另有「信息/警告/错误」。
- 账号折叠、日志筛选、页签选择、设置里未保存的输入都跨页签保留。
- 账号卡的运行时长取自「本次运行起点」（优先平台 start_time，否则 App 首次观察到 RUNNING 的时刻并持久化），不再误用工作区 create_time；折叠行显示「已运行」，展开行把「分支 · 实例 · 已运行」压成一行，地址单独显示并提供「复制」。
- 内容区支持**左右滑动切换页签**（底栏点击仍可用），纵向滚动与设置页拖动排序互不冲突；翻页限制为一次一页、预组合相邻页、点击页签平滑动画，避免快速滑动跳页和卡顿。
- 备份导出/导入使用系统文件选择器，可自己选目录与文件；WebDAV 地址/账号/密码改为独立草稿，必须点「保存 WebDAV」才生效，上传/下载前会自动提交；WebDAV 下载或本地选文件后先弹「恢复备份？」预览（来源/范围/账号数），确认后才按仓库合并恢复。
- 切换页签时主动清除输入焦点并收起输入法，避免其它页面继续弹出键盘。
- 仪表盘的账号行与账号页不重复放操作按钮：点仪表盘行会跳到账号页并**只展开该账号**，详情与启动/刷新/删除集中在账号页。
- 底部导航顺序用**上下拖动**调整；设置页不显示无效开关，改为「固定」标记；显隐与顺序改动即时生效，保存后持久化。
- 「关于」页：显示应用图标、版本与构建号、包名、构建类型、最低系统、开源仓库/发行版本/问题反馈链接，以及第三方开源组件清单。

## 10. 对照插件 0.9.12 的审计

已移植 / 修复：

- 账号列表按「可用 credits」降序排列，可用多的在前，额度未知/已用尽排后。
- 地址展示保留**非临时**的移动数据 IPv6（IPv4 移动数据仍隐藏，因为局域网不可达）；界面不显示 `rmnet_data` 等底层网卡名。
- 本地账号备份/还原：范围（账号/设置/全部）、**与插件完全一致的格式**（`data` 包裹、scrypt N=16384/r=8/p=1、AES-256-GCM 且 tag 独立字段）、账号/设置白名单、按仓库小写合并、`gatewayKey` 不入备份；JVM 单元测试覆盖插件加密备份解析。
- WebDAV 上传/下载与「保存后自动上传」：目录自动补文件名、拒绝 `#`/`?`、Basic 认证、30s 超时、404 单独提示；自动上传 1.5s 防抖，且**必须设备份口令**（避免明文令牌静默上云）。
- 设置自动保存的稳定性修复：输入框不再因为每次 autosave 改 key 而重置焦点；备份导出使用当前本地草稿而不是 1 秒前的快照；还原设置后表单同步刷新；主题色/导航顺序恢复即时预览。

尚未移植（明确差异）：

- **设置分组默认折叠**：插件 0.9.12 把「余额与提示」「其它」「备份与还原」默认收起、状态面板默认收起；本项目设置页分区常展开，未做折叠。

已知限制（沿用）：

- `/health` 不鉴权；`/v1/models` 本地生成（工作区停机也能发现模型）；chunked 请求体需 `Content-Length`；留空备份口令时文件为明文（含令牌），需自行保管。
